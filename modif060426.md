¡No! Las direcciones de ballenas se agregan automáticamente. Lo que sí necesitas agregar manualmente son los contratos de los tokens que quieres escanear (en WHALE_HUNT_TARGETS).

El flujo es:

Tu defines el contrato del token ($WIF)
        ↓
hunt_whales_by_pair_task() lo escanea via GeckoTerminal/DexScreener
        ↓
Encuentra los mayores compradores automáticamente
        ↓
Los agrega como WhaleWallet en la DB con target_pairs="WIF"
La única cosa manual son los contratos de tokens. Aquí va una guía rápida para encontrarlos:

Cómo encontrar contratos de tokens para agregar a WHALE_HUNT_TARGETS
1. DexScreener (más fácil)
Ir a dexscreener.com
Buscar el token (ej. WIF)
Hacer clic en el par que te interese
Copiar la dirección que aparece bajo "Pair Contract" o "Base Token"
2. CoinGecko / CoinMarketCap
Buscar el token
Ir a la sección "Contract" o "Token Info"
Hay un pequeño icono de copiar junto a la dirección del contrato
3. Dónde pegar la dirección
En criptodash/dashboard/tasks.py, en el diccionario WHALE_HUNT_TARGETS:

python
WHALE_HUNT_TARGETS = {
    'solana': [
        'EKpQGSJtjMFqKZ9KQanSqYXRcF8fBopzLHYxdM65zcjm',  # $WIF
        # ← Pegar aquí los contratos de Solana
    ],
    'ethereum': [
        '0x6982508145454ce325ddbe47a25d4ec3d2311933',  # $PEPE
        # ← Pegar aquí los contratos ERC-20
    ],
    'base': [
        # ← Pegar aquí los contratos de Base
    ],
}
4. Identificar la blockchain correcta
Si la dirección empieza con...	Blockchain
0x... (42 chars)	ethereum o base
Letras/números, ~44 chars	solana
0x... en Hyperliquid	hyperliquid
5. Validar antes de agregar (recomendado)
Puedes usar el Whale Scout que ya existe en tu dashboard (buscador por contrato) para verificar que el contrato devuelve resultados antes de agregarlo al diccionario permanente.
